              GitHandler
              
					
              Nessun repository aperto.
              
					
              
						
						
						
						
					
              
					
              
						La cartella di base è —:
						da lì partono i dialog e i cloni, poi si naviga dove
						serve. Si cambia nelle impostazioni.
					
              
				
              
			
              
		
              

		
			
              
				
              Impostazioni
              

				
              
					
              Cartella di base
              
					
              
						Da qui partono «Apri», «Crea» e «Clona». Non è un
						limite: nella finestra di scelta si può navigare
						ovunque.
					
              
					
              
						
						
					
              
				
              

				
              
					
              Aspetto
              
					
              
						Colori, densità e dimensione del testo. Il tema
						«Automatico» segue il sistema; «OLED» usa il nero
						assoluto.
					
              
					
              
						
						
						
						
						
						
					
              
				
              

				
              
					
              Lingua
              
					
              
						La lingua dell'interfaccia. «Automatica» segue quella
						del sistema.
					
              
					
              
						
						
					
              
				
              

				
              
					
              API per l'AI (server MCP)
              
					
              
						Il server espone solo i comandi consentiti qui, e la
						policy viene riletta a ogni richiesta. Il default è
						spento: un agente collegato non vede nulla finché non lo
						si abilita.
					
              
					
					
					
					

					
              
						
						
						
						
						
						
              Scrittura
              
						
						
						
						
						
					
              
				
              

				
              
					
              File non tracciati
              
					
					
              
						
						
						
						
						
						
					
              
					
              
						Le copie sono oggetti Git
						(refs/githandler/trash): compresse,
						deduplicate e mai inviate al remoto. Oltre i limiti lo
						scarto si ferma; quando lo spazio totale è pieno si
						eliminano per prime le copie più vecchie.
					
              
					
              
				
              

				
              
					
					
				
              
			
              
		              

		
			
              
				
              Stash
              
				
              
					Lo stash salva modifiche e file non tracciati e lascia il
					working tree pulito. Riprendere uno stash lo rimette sui
					file; «Pop» lo applica e lo elimina.
				
              
				
              
					
              
						File da salvare
						
						
					
              
					
              
					
              
						Con una parte dei file, gli altri restano nel working
						tree.
					
              
				
              
				
              
					
					
				
              
				
                
				
                
					
				
                
			
                
		                

		
			
                
				
                Submodule
                
				
                
					«Aggiorna» esegue
					git submodule update --init --recursive:
					scarica e allinea i submodule al commit registrato.
				
                
				
                  
				
                  
					
					
				
                  
			
                  
		                  

		
			
                  
				
                  Crea un repository
                  
				
                  
					git init nella cartella scelta. Se compili nome
					e email diventano l'identità locale del repository;
					vuoti, restano quelli globali di Git.
				
                  
				
				
				
                  
					
					
				
                  
				
                  
					
					
				
                  
			
                  
		                  

		
			
                  
				
                  Clona un repository
                  
				
                  
					Un URL HTTPS, SSH o un percorso locale. Il repository prende
					il nome dalla sua ultima parte e finisce nella cartella
					scelta.
				
                  
				
				
				
                  
				
                  
					
					
				
                  
			
                  
		                  

		
			
                  
				
                  Account collegati
                  
				
                  
					Il token serve per elencare i repository e per clonare
					quelli privati; GitHandler non lo scrive su disco. Tre
					strade, dalla più semplice:
					Accedi con il token del computer usa un
					token che hai già (GitHub CLI o credential helper di Git);
					Accedi con il browser apre il browser e
					richiede un Client ID OAuth registrato;
					Crea un token sul sito… apre la pagina dei
					token e poi lo incolli qui sotto.
				
                  
				
                  
					
                  
						
                    
						
                    
							
							
						
                    
					
                    
					
                    
						
						
                    
							
							
						
                    
						
						
						
						
                    
							
							
							
							
						
                    
						
						
                    
							
							
						
                    
					
                    
				
                    

				
                    
					
                    
						Repository dell'account
						
					
                    
					
                    
						
					
                    
					
                      
					
					
                      
						Clona in
						
						
					
                      
				
                      

				
                      
					
				
                      
			
                      
		                      

		
			
                      
				
                      Apri un file del repository
                      
				
                      
					File tracciati in HEAD. Doppio clic per aprire con
					l'applicazione associata.
				
                      
				
                      
					
				
                      
				
                        
				
                        
					
					
					
					
				
                        
			
                        
		                        

		
			
                        
				
                        GitHub Actions
                        
				
                        
					Ultime esecuzioni del repository. «Riprova i falliti» ripete
					solo i job falliti, «Ri-esegui» l'intero workflow; «Annulla»
					ferma un'esecuzione in corso.
				
                        
				
                        
					Esecuzioni
					
				
                        
				
                          
				
                          
					
					
				
                          
			
                          
		                          

		
			
                          
				
                          Pull request
                          
				
                          
					Richieste aperte sul servizio del repository. Se ne crea una
					da due rami già inviati con Push; «Apri» mostra la pagina
					web della richiesta.
				
                          
				
                          
					Aperte
					
                          
						
						
					
                          
				
                          
				
                            
				
                            
					Nuova
					
					
					
                            
						
						
					
                            
					
                            
						
					
                            
				
                            
				
                            
					
					
				
                            
			
                            
		                            

		
			
                            
				
                            Reflog
                            
				
                            
					Ogni spostamento di HEAD, dal più recente: commit, checkout,
					reset, rebase. «Vai al commit» apre quel commit nel
					pannello; non cambia il repository.
				
                            
				
                            
					Aggiornamenti di HEAD
					
				
                            
				
                              
				
                              
					
					
				
                              
			
                              
		                              

		
			
                              
				
                              Salute del repository
                              
				
                              
					Cose che non impediscono di lavorare ma è meglio sapere:
					rami divergenti, stash dimenticati, submodule non
					aggiornati, HEAD staccato.
				
                              
				
                              
					Controlli
					
				
                              
				
                                
				
                                
					
					
				
                                
			
                                
		                                

		
			
                                
				
                                Cerca nel contenuto
                                
				
                                
					Cerca nei file tracciati con git grep. Il testo è letterale
					salvo «Espressione regolare»; clic su un risultato per
					aprirlo nell'app del sistema.
				
                                
				
                                
					
					
				
                                
				
                                
					
					
				
                                
				
                                  
				
                                  
					
					
				
                                  
			
                                  
		                                  

		
			
                                  
				
                                  Titolo
                                  
				
				
                                  
					
					
				
                                  
			
                                  
		                                  

		
			
			
                                    
			
                                    
				↑ ↓ per scorrere · Invio per eseguire · Esc per
					chiudere
