            API per l'AI (server MCP)

            Il server espone solo i comandi consentiti qui, e la policy viene riletta a ogni richiesta. Il default è spento: un agente collegato non vede nulla finché non lo si abilita.

            File non tracciati

            Le copie sono oggetti Git (refs/gitcraft/trash): compresse, deduplicate e mai inviate al remoto. Oltre i limiti lo scarto si ferma; quando lo spazio totale è pieno si eliminano per prime le copie più vecchie.
